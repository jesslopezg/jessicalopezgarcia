# Jessica Lopez-Garcia — Academic Website

Personal academic website for Jessica Lopez-Garcia, PhD.

## Live site

Once GitHub Pages is enabled for the main branch at repository root, the site URL is:

https://jesslopezg.github.io/jessicalopezgarcia/

## Publishing

Go to **Settings → Pages → Build and deployment**, select **Deploy from a branch**, then select **main** and **/(root)**. Save the configuration.

## Editing

- `index.html`: website content, SEO metadata and academic links.
- `styles.css`: visual identity and responsive layout.
- `script.js`: mobile navigation and copyright year.

Publications are linked to verified public academic profiles rather than listing unverified bibliographic metadata. Add confirmed titles, DOI links, and dates before publishing a full bibliography.

No build step or dependencies are required.
